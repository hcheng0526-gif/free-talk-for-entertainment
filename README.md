### 💡 项目初衷
在当代婚恋/交友市场中，沟通低效和三观错位导致了大量的时间损耗与情感伤害。本项目旨在通过“前置化”的三观博弈测试，在双方投入深度情感成本前，利用 AI 发现并翻译潜在分歧，将“冲突”转化为“理解”。

### 🚀 技术架构
- **Frontend:** 极简轻量化的 HTML5, CSS3 (Tailwind-like), Vanilla JS 架构。
- **Deployment:** 基于 Netlify 的持续集成（CI/CD）自动化部署。
- **AI Backend (Roadmap):** 计划深度接入**小米大模型 (MiLM)**，实现从“数据对比”到“语义理解”的跨越。

### 🤖 AI Agent 工作流预览 (核心逻辑)
本项目计划利用大模型对用户的分歧点进行“中立化、非对抗性翻译”，核心流程如下：
1. **分歧抓取：** 实时提取双方分歧度 ≥ 2 的选项（基于双人博弈数据包）。
2. **底层逻辑识别：** 调用 LLM 分析选项背后的安全感来源、消费心理或社交边界认知。
3. **沟通话术生成：** 将原始冲突点转化为建设性的沟通建议，生成《双人关系对齐报告》。
