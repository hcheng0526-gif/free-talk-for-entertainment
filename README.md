# 镜像坦白局 (Mirror Heart Sync)

本项目是一款基于双人博弈算法的价值观对齐工具。

### 🚀 技术架构
- **Frontend:** HTML5, CSS3 (Tailwind-like), Vanilla JS.
- **AI Backend (Plan):** 接入小米大模型，用于处理双人选项的分歧语义分析。
- **Deployment:** Netlify 自动化部署。

### 🤖 AI Agent 工作流预览
本项目计划利用大模型对用户的分歧点进行“非对抗性翻译”。
1. 提取双方分歧度 >= 2 的选项。
2. 将原始冲突转化为建设性建议。
3. 生成中立的深度沟通报告。
